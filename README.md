A small program that prints one sentence (149 characters) explaining the modern internet to a time traveler from 1800: a letter that crosses an ocean in the blink of an eye, borne on thin wires, so any soul on earth may speak with any other soul at once. Every word in it was already in use before 1800.

## Run it

```sh
python3 main.py
```

Standard library only; the output is byte-identical on every run.
